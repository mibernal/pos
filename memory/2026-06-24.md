# 2026-06-24: Corrección de Deuda Técnica, Sync Offline y Auditorías Arquitectónicas

## Qué sucedió hoy
- Se resolvieron fallos críticos de Sincronización Offline que causaban un bucle infinito de errores `409 CASH_SESSION_CLOSED` al intentar empujar ventas guardadas en sesiones de caja que ya habían sido cerradas.
- Se reparó un `Internal Server Error (500)` masivo en `create-sale.service.ts` ocasionado por un `JOIN` a la tabla huérfana `tenant_modules`.
- Se solucionó la lógica de "Órdenes Fantasma" donde no se permitía modificar flags de tenant asumiendo equivocadamente que habían órdenes abiertas.
- El sistema de WebSocket y Node Proxy Vite fue estabilizado.
- Se generaron cuatro artefactos de auditoría de arquitectura y código muerto a nivel de Principal Architect y Comité.

## Decisiones Técnicas & Fixes
1. **Auto-Reasignación de Sesiones Offline:** En `create-sale.service.ts`, si una venta llega desde PouchDB/LocalStorage con un `cash_session_id` que ya fue cerrado, el backend ahora ejecuta una consulta para interceptar la sesión *activa* actual en esa sucursal y auto-asigna la venta. Esto previene pérdidas de dinero por desincronización de cajas.
2. **Eliminación Definitiva de `tenant_modules`:** La arquitectura migró oficialmente a flags incrustados directamente en la tabla `tenants` (`enable_tips`, `enable_delivery`, etc.). Todo rastro de `tenant_modules` está deprecado y genera deuda técnica.
3. **Auditoría de Frontend (Zustand):** Se identificó un riesgo crítico donde `useCartStore` persiste `tableCarts` en `localStorage`, aislando los pedidos de mesa físicamente por tablet, rompiendo el flujo multi-mesero. Se recomendó extraerlo.
4. **Auditoría de Mesas (Backend):** Se descubrió que `saveTableOrder` borra iterativamente (`DELETE`) todos los ítems de mesa al actualizar, lo que destruye el historial del KDS (`sent_to_kitchen_at`) y pierde los modificadores de productos.
5. **FinOps & Cloud:** Se definió un plan de lanzamiento MVP (Cloud Run + Managed DB + Upstash Serverless) que permite bajar los costos operativos a ~$30/mes apagando temporalmente el stack pesado de observabilidad (Tempo, Loki, Grafana) hasta la Fase de Crecimiento.
